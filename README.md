
# ☕ AcunMedyaCafe 

Bu proje, modern bir **kafe web sitesi** için geliştirilen bir **ASP.NET Core MVC** uygulamasıdır. Projede yönetim paneli (admin), ürün ve kategori yönetimi, görsel destekli ürün tanıtımları, istatistiksel dashboard ve kullanıcıdan gelen mesajları yönetme gibi birçok özellik bulunmaktadır.

## 🔗 Admin Panelinde Bilgilendirici Link

Admin paneli ana sayfasında yer alan **"ASP.NET Core"** yazısına tıklanarak **"ASP.NET Core Nedir?"** başlıklı Medium yazıma ulaşabilirsiniz:

👉 [ASP.NET Core Nedir?](https://medium.com/@narinuluisik7/modern-web-geli%C5%9Ftirmenin-kalbinde-asp-net-core-2647f4ee0507)


## 🚀 Teknolojiler

- ASP.NET Core MVC
- Entity Framework Core
- MSSQL Server
- Bootstrap 5
- FluentValidation
- Linq Sorgular
